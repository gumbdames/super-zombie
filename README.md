# סופר זומבי / Super Zombie

## 🇮🇱 עברית

**סופר זומבי** הוא משחק הרפתקאות תלת־ממדי לילדים — בלי אלימות, בלי נשק ובלי הרג!
אתם משחקים את **מצווה בוי** או **מצווה גירל**, ומסתובבים בחצר בית החינוך בלילות מלאי זומבים.
במקום להילחם, הזומבים **חוזרים בתשובה** 🙏 — מתפללים, רוקדים, ואפילו מקבלים כיפה וציצית.

**ארבעת הכוחות:**
1. 🙏 תפילה — "מודה אני לפניך"
2. 📯 שופר — תקיעה שמדיפה את הזומבים לאחור
3. 🎫 כרטיס מצווה — אוספים 12 ומקבלים כרטיס תפארת
4. ✡️ תפארת — מחזירה בתשובה את כל הזומבים בבת אחת

בנוסף: כוח הפלוץ / כוח השירה 💨🎵, וואן ברסלב עם ניגון 🎶, חוג תורני עם הרב, חיות, ציפורים ופרחים.

**חמישה שלבים:** בית חינוך בילו ← חב״ד ← אריאל ← נועם ← יבנה.
בכל שלב שורדים מחזורי יום ולילה, אוספים כרטיסי מצווה, ונכנסים לפורטל הזוהר לשלב הבא.

**שליטה במחשב:** תנועה WASD/חצים • מבט: עכבר • קפיצה: רווח • כניסה לוואן: E • שימוש בכוח: קליק/F • החלפת כוח: Q • 💨/🎵: X • הפסקה: P

**שליטה בטלפון:** ג׳ויסטיק לתנועה • 🙏 שימוש בכוח • 🔄 החלפת כוח • 🚐 וואן • 💨/🎵 כוח מיוחד • ⬆️ קפיצה

**קובץ אחד, עובד אופליין:** המשחק הוא קובץ HTML יחיד — פשוט פותחים אותו בכרום (במחשב או בטלפון) ומשחקים, גם בלי אינטרנט.

## 🇬🇧 English

**Super Zombie** is a 3D adventure game for kids — no killing, no weapons, no violence!
You play as **Mitzvah Boy** or **Mitzvah Girl**, exploring the schoolyard on zombie-filled nights.
Instead of fighting, the zombies **repent** 🙏 — they pray, dance, and even get a kippah and tzitzit.

**The four powers:**
1. 🙏 Prayer — "מודה אני לפניך"
2. 📯 Shofar — a blast that knocks zombies back
3. 🎫 Mitzvah card — collect 12 to earn a Tiferet card
4. ✡️ Tiferet — makes every zombie repent at once

Plus: the fart / song power 💨🎵, the Breslev van with its niggun 🎶, the Rabbi's Torah circle, animals, birds and flowers.

**Five levels:** Bilu ← Chabad ← Ariel ← Noam ← Yavne.
In each level you survive day/night cycles, collect mitzvah cards, and enter the glowing portal to the next level.

**Desktop controls:** Move WASD/Arrows • Look: mouse • Jump: Space • Enter van: E • Use power: Click/F • Switch power: Q • 💨/🎵: X • Pause: P

**Phone controls:** Joystick to move • 🙏 use power • 🔄 switch power • 🚐 van • 💨/🎵 special power • ⬆️ jump

**One file, works offline:** the game is a single HTML file — just open it in Chrome (on a computer or a phone) and play, even without internet.
